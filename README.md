# H2walk

H2 人形机器人的 Isaac Lab 任务、控制网络与 LiDAR 地形重建源码。

本分支目标是让同一 H2 策略兼顾普通地形和上下楼梯。Stairs任务保留GT扫描和混合地形，采用地面相对净空与宽窄带宽混合跟踪；修正低速、yaw限幅时的奖励门控，训练按固定地形列逐组达标后扩速，并提供配套目标上限的20cm渐进档案。各项保留基线开关。main新增项经接口与CPU反例检查后选择性适配。没有运行训练、仿真或真机实验，尚未证明正常行走或20cm通过能力。

新上传的30k日志表明基础稳定性尚未建立。新增独立 `Stairs-Diagnostic` 以及 `Walk-Bootstrap/Shallow/Stairs08/12/16/20` 任务：reset前区分地面/自身接触，保留扫描做低速平地基础训练，按平地/上楼/下楼的实际进度与支撑高度证据给出下一档建议。旧任务不变；新Walk使用固定观测缩放、关闭RND，须从零开始Bootstrap，不能直接resume旧归一化checkpoint。

10月30日的新18224轮记录仍属旧混合配置：回报和存活提高，但有效推进中后段下降，尚无成功行走证据。新Walk默认增加交替落脚、实际有符号推进、摆动周期nearest目标保持和支持代理，保留legacy对照；checkpoint协议升级v2，旧v1不自动迁移。源码与CPU性质修复尚未动态验证。
