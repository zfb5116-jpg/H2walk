# H2 自主上楼梯目标

机器人通过自身策略控制十二个腿关节，在保留原生驱动、关节限位、传感器随机化和身体终止条件的情况下完成上楼梯。上身十七个关节维持原有默认目标，不使用参考步态、额外重心控制或人工扶持。

训练从已独立通过平地门槛的策略出发，使用真实激光雷达重建的地形信息。输入包含原有五帧身体状态和五维运动上下文。继承的归一化保持冻结，优化状态与随机状态从新任务开始建立。

新建楼梯训练在继承策略后，将十二个腿关节的随机探索标准差初始化到各自原有物理角度均方根上限。单侧髋俯仰、髋侧摆、髋偏航、膝、踝侧摆与踝俯仰的上限依次为零点零二、零点零一五、零点零一五、零点零二、零点零一与零点零零七五弧度，左右相同；最小标准差保持为各自上限的百分之五。训练中标准差可在原有边界内学习，关节确定性目标与完整动作范围保持原有权限。计划、启动请求、实际初始化、训练记录和模型记录共同核对这些参数；平地与通用训练的初始化比例保持原值。

楼梯训练的回报折扣与广义优势累计系数均为零点九九，每轮连续采样四十八个控制步，每步零点零二秒。每轮实际采样时长为零点九六秒，优势累计只使用这段采样内已有的时序残差及原有末端价值估计，并保留回合结束边界。计划、启动请求、解析后的训练配置、实际算法参数、实际采样存储、原生训练记录和模型记录共同核对这些时间参数。更晚残差的权重用于本任务学习，其上楼效果仍须由独立物理验收判定。

固定约束输入仅取新训练首轮最初二十四个真实控制步，分为四组连续六步，每组覆盖全部一千零二十四个环境一次，总计四千零九十六行。在真实第二十四步结束后、下一次动作产生前完成封存，此时尚未进行优化或末端价值估计，随机网络真实采样计数为二十四。该时点当前采样行数为五百二十，完整的当前一千零二十四行要到第四十八步结束后才收齐。每轮当前输入按四十八个真实控制步分配，前十六步各二十二行，其余三十二步各二十一行，与已封存固定输入共同组成原有五千一百二十行约束输入。封存和后续采样不增加策略或价值网络查询。

楼梯训练预建五、十、十五厘米三档真实台阶，每档均包含六级，踏面深三十五厘米、宽二点四米，接近距离一点四米。固定二百五十六个环境始终使用十五厘米目标高度，其余七百六十八个环境从五厘米开始。环境在首次重置、观测和策略采样之前就分配到对应真实地形；不向策略增加高度标签。原始根部水平起点分布保持不变。

课程环境仅在真实回合结束后的正常重置时晋升到下一档高度，单次最多升一档。晋级使用当前高度最近五个真实结束回合，初始不完整回合除外；至少四个回合取得中间技能证书才晋级。证书要求在同一个仍存活的真实控制时刻同时达到：回合存活至少二十秒、前两级双脚均有合格落脚和真实载荷交接、根部净上升为正、倾角小于零点五弧度。该回合后续出现物理无效或力证据不合格，证书作废；未取得证书、早跌及无效回合均保留为五个回合的分母。证书只用于课程晋级，后来发生的原身体终止仍是任务失败，不能作为完整上楼成功。晋级不要求先完成完整六级九十秒任务，也不提前结束回合、动态修改台阶网格或改变身体初始姿态。

运动目标固定为世界楼梯方向每秒三十厘米，并按当前完整姿态转换为原有身体坐标速度指令；原输入单位、身体坐标语义和冻结归一化保持不变。根刚体质心与根部原点的世界速度分别记录，避免混用测量位置。逐级有效交替落脚、持续承重、机器人根部实际净上升和顶部稳定停留构成训练中的进展证据。全回合接触力证据不合格后，不再获得该回合正向进展奖励，向后运动负债仍完整计入。

训练目标还包括抑制倾斜继续扩大，以及让腾空脚掌完整越过真实台阶边缘。脚前缘进入立面前五十五厘米时，净空要求从下方踏面连续抬升，在立面前二十厘米达到实际一级高度另加两厘米；净空不足按实际阶高另加两厘米归一化。目标保持到脚掌最后缘越过该立面并留出八毫米余量，再转向后续真实台阶。非正代价要求本脚卸载、另一脚实际承受至少七成体重；向前运动比例控制代价强度，进入五十五厘米范围后该比例至少为四分之一，因此静止或后退的低脚也会得到有限负反馈。更远处只保留向前运动时低于下方踏面的代价，不向远处平地扩展静止代价。六条真实立面全部越过后结束该代价，顶部稳定和最终验收另按原条件判定。这些训练代价不指定步态相位、关节目标或固定身体高度，也不向策略额外提供仿真几何信息。提前和持续的负反馈仍可能诱导回避或不卸载，不能仅凭代价上界认定激励已经正确。

持续倾斜超过零点一弧度后，训练代价随偏离程度平方增长，恢复姿态通过减少后续损失获得引导，不额外支付站立或存活奖励。动作连续性同时考察十二个有界动作的平均变化和最大的单关节变化。只比较同一真实回合内已有的相邻控制动作，首次实际控制不与填充历史或上一回合动作比较，初始不完整回合也使用真实控制计数。动作代价不改变关节命令、执行延迟、速度和力矩权限。

从同一真实立面前二十厘米开始，训练还记录左右脚各自整脚最低角相对下方踏面的净空进展，以便在首次有效落脚之前为实际抬脚提供反馈。每脚状态限制在零到一，按零点九九折扣计算前后差分，以固定系数一加入已有进展奖励。正差分仅在本脚卸载、另一脚承受至少七成体重、双脚当前力证据有效、根部倾角小于原正向进展使用的零点五弧度，且回合力资格和速度条件允许时计入；进入接近区域或切换目标立面本身不获正信用。左右脚分别处理，原进展奖励也独立处理；所有下降负差分保留。初态使用实际控制前的脚掌姿态，真实终止、超时和物理无效端点在奖励计算前结清状态，正常采样边界不清除历史。该反馈不计为有效上阶落脚，不改变身体终止条件、有效落脚资格或最终验收；倾斜、动作变化和净空不足分别按各自的训练代价计算。静止不产生该项正收益，闭合抬放循环不能获得该项净收益；其学习效果仍须由新训练和独立物理验收确认。

训练还通过真实后续接触和支撑结果学习触地前的落足质量。每次实际控制只使用当时已有的身体输入及实际收到的动作，预测随后首次可观察接触的脚底中心位置、整掌落足条件及接触后局部支撑恢复。首次接触最多观察零点六四秒，其后局部恢复再观察零点六四秒，禁止挑选更好看的后续接触替代首次接触。支撑结果要求实际承重、另一脚卸载、姿态恢复及同脚同级原有效上阶证据；第零级平地可提供单独的训练标签，但不计为上阶。该局部结果不能替代九十秒稳定性或最终验收。

触地前反馈从真实立面前六十厘米开始，以二十五厘米前的准备区、整脚最低角高度和全脚掌后缘跨面进展共同引导起抬选择。六条真实立面同时参与实际几何状态，预测器只减少正差分的付费比例，原有速度、卸载、另一脚承重、姿态和力资格门仍有效；正向保留比例最低为四分之一。负差分完整保留，模型更新本身不改变几何势，也不产生正收益。真实终止、超时、物理无效、力资格失效及已知预算末端在奖励消费前结清；外部中断来不及结清的实际负债单独保全，不能伪称已经闭合。

未来尚未观察完整、初始不完整回合及跨重置边界的样本保留未知标识，不补成失败零值，也不跨回合拼接。训练模块与原策略参数独立，不增加策略输入、不覆盖关节目标。原最初四十轮仅进行原价值预热及该模块的影子学习，之后须以固定保留环境上的真实标签通过校准，才允许其参与下一轮正反馈；校准不足或不合格即停止并保全，不延长预热或预算。新增数据存储独立限于五百一十二兆字节，训练模块自身的图形设备张量限于一百二十八兆字节，原动作约束资源边界保持不变。正式验收只使用原策略与原场景，不启用此训练模块。

训练使用一千零二十四个环境，上限一千轮，每轮四十八个控制步，自然完成时共四千九百一十五万二千个环境步。约五百轮的完整模型保存后，检查预定三个各含五千个完整回合的固定十五厘米目标环境窗口；若均没有接触力证据合格的有效上阶落脚，则提前停止、保全记录并复盘修复。低台阶课程环境及后来晋升到十五厘米的课程环境单独记录，不能混入固定目标组的停止窗口。目标窗口不足或数值非有限时，不补零、不发零进展停止信号，也不延长预算。出现有效上阶进展则继续至原上限。失败和无效回合保留在分母中，未完整记录的初始回合不计入滚动窗口。数值、资源或物理监督条件优先执行，不自动延长或重试。训练指标与数值检查只用于监督，不代表上楼梯已经通过。

训练在同一个一千零二十四环境仿真中录制固定目标组首个环境的短窗视频，按真实控制步、已接受更新数及回合重置标识记录。视频分辨率为五百一十二乘三百八十四，每秒十帧，前、中、后窗口总计最多五百帧；未到达的窗口和中断窗口不补跑仿真，不为录像延长训练。录像使用原有视图渲染，不增加感知相机或修改物理、雷达更新周期；实际画面、资源和文件完整性须由本次真实运行核实。

训练还在终态重置之前记录十九项实际加权奖励贡献、两脚净空原始差分与实际付费差分、资格条件及动作状态。按真实高度和环境组统计条件交集和积分，并记录约束输入的实际高度组成；这些观测记录不进入策略输入，不额外查询策略或价值网络，也不能替代有效落脚和正式验收。

中间录像对应的有限执行记录在控制开始、实际动作采样之后且物理推进之前，复制策略已经使用的归一化地形输入、已有雷达重建高度图、射线有效比例和各自生成时刻，并保留地图坐标与实际根部姿态的配准信息。缺失或过期信息明确标记，不补成零值，不重新查询传感器、重建网络或策略网络。该记录用于区分地形信息是否正确呈现，以及策略是否形成相应的上阶动作；存在输入通路本身不能证明正确识别或利用地形。

候选落脚约束的策略输出和导数使用与完整输入检查相同的原始批次，在得到批次输出后选取实际输入行，并独立核对前向结果与方向导数的一致性。原动作变化、数值误差和资源边界保持不变。

最终验收在 Isaac Sim 中独立执行一千零二十四个环境的首个完整九十秒回合。每个成功环境必须同时满足：

- 完成六级十五厘米台阶，每级双脚均有原有效交替落脚。
- 落脚前有效腾空八十至六百毫秒，承重持续至少八十毫秒。
- 全脚掌前后留有至少八毫米、侧面至少二十毫米余量。
- 真实净上升九十厘米，容差十厘米；顶部稳定至少两秒。
- 全回合存活，并保留同脚地面过滤力与原始力的正对照和一致性证据。

失败和无效环境均保留在完整分母中。至少九百二十二个相同环境同时满足全部条件，才认定本目标通过。平地通过、训练完成、检查通过或程序正常退出均不能代替这项验收。
