# 按实际前进量扩速的命令课程

日期：2026-10-23。增量基线：用户分支 `C1801SYQ/h2walk-algorithm-optimization` 的 `cebcf65ba80842bd8675e7ed8f919f9944d17d31`。本轮不使用重建归档，不启动训练、仿真或真机，不执行优化器更新。

## 原课程的问题与本版目标

原 `lin_vel_cmd_levels` 仅判断速度指数奖励是否超过权重的 0.8，并在 `common_step_counter % max_episode_length == 0` 的 reset 子集上评估。小命令下即使静止，指数奖励也可能足够高；只有恰巧在整倍数步重置的环境被采样，异步 reset 的证据容易遗漏。

本版以实际世界位移为必须条件，聚合完成回合，默认只扩展 X 前后速度范围。侧向 Y 和转向 Z 范围不随之扩大；前进成绩不能代替侧移能力。新课程不依赖原速度奖励的私有回合积分。

## 怎样累计实际进度

每个控制步开始时，保存实际生效的命令、根部 XY 位置和 yaw，不能使用步进结束后已重采样的新命令。设本步时长为 `dt`、局部前后命令为 `c_x`，yaw 水平前向单位向量为 `e_x`，实际水平位移为 `delta_p`。

当 `abs(c_x) >= command_progress_min_speed` 时累计：

```text
forward_target_distance += abs(c_x) * dt
forward_signed_progress += sign(c_x) * dot(delta_p, e_x)
forward_active_time += dt
```

停止或小 X 命令阶段不赚取上述有效进度，但额外累计 `inactive_forward_error += norm(delta_p-command_world_xy*dt)`。这里使用完整 XY 命令残差，避免转向后把停止命令下的回退藏成侧漂；正确侧向或小命令跟踪的残差仍为零。评估时使用 `effective_progress = forward_signed_progress-inactive_forward_error`：先前进、再错误退回，不能保留全部过关信用。这个累计误差约束也会计入停止时的平移摆动，门槛尚需后续实验校准。

默认最低命令速度为 0.1 m/s。后退命令按其方向计正进度；固定命令下退回原处会抵消原有正进度。没有把每一步负进度截成零，也没有使用路程绝对值来奖励原地往返。另保留总 XY 命令方向的目标距离/进度，作为诊断，但不让纯横移或斜向漂移替代 X 进度。

具体数据流已核对 Isaac Lab [v2.1.0](https://github.com/isaac-sim/IsaacLab/blob/v2.1.0/source/isaaclab/isaaclab/envs/manager_based_rl_env.py) 和 [v2.2.1](https://github.com/isaac-sim/IsaacLab/blob/v2.2.1/source/isaaclab/isaaclab/envs/manager_based_rl_env.py)：physics 后先计算终止和奖励，再 reset，最后重采样命令。

- `RobotEnv.step` 调父类前捕获本步状态。
- `_reset_idx` 调父类前结算终止环境最后一步，使课程在 reset 前读到完整数据。
- 父类 reset 后只清本批环境，保留其他环境的累计值。
- 父类 step 返回后仅结算剩余 pending 环境；同一步不会重复消费，也不把 reset 的传送位移算作前进。

单步位移大于 `command_progress_max_step_speed * dt`（默认阈值 5 m/s）、非有限状态，或两步之间位置发生不连续变化，都会将整回合证据标为无效。正常 reset 后允许更换起点。当前 interval push 仅改变速度；这些 guard 不保证识别任意外部传送，也不是安全控制器。

## 回合怎样过关

每个自然终止回合先独立判断是否达标，而不是用少数快速环境的平均位移掩盖静止环境。

| 默认条件 | 值与作用 |
| --- | --- |
| 超时且无失败终止 | `time_out=True` 且 `terminated=False`；两者同时触发按失败处理 |
| 存活时间 | 至少最大回合时间的 98% |
| 有效 X 命令暴露时间 | 至少 2 秒 |
| 累计 X 命令距离 | 至少 0.5 m |
| 有效 X 进度/命令距离 | 扣除停止/小命令阶段误差后至少 0.8；原主动阶段进度比还必须不超过 1.2，过快不自动算成功 |
| 数据与阶段 | 本回合数据有效，属于当前课程 generation |

有 X 命令暴露但早跌倒、时间或距离不足的自然终止回合，仍进入分母并判失败。有效的站立、纯转向、纯侧向回合不提供 X 扩速成绩。无效数据的自然终止回合保守计失败，即使命令损坏导致没有记录到暴露。初始化 reset、外部手动 reset不提供自然完成成绩。

异步 reset 的回合持续累计；到达评估间隔且至少有 32 个回合时评估。间隔默认取环境的最大回合步数，判断使用 `>=`，无需恰好整除。至少 80% 回合达标才扩大 X 范围两端各 0.1 m/s，并限制在原 `limit_ranges.lin_vel_x` 内。Y/Z 保持原值。

每次评估后清窗口、更新评估时刻；真正扩速后增加 generation。扩速前已经开始而尚未结束的回合不会变成新阶段成绩，完成 reset 后才进入新阶段。范围已经达到上限时不增加 generation。相同 reset 批次重复调用不会重复计分。

这些值是可解释的初始工程门槛，没有通过训练调优。本版只评价当前采样分布上的前后命令跟踪，不分别证明最高速度、前进/后退各方向或所有地形上的能力。

## 修改位置、开关和日志

H2 任务路径为 `source/CtrlLab/CtrlLab/tasks/manager_based/h2_task/`：

- `command_progress.py`：纯 tensor 步进/回合统计。
- `progress_curriculum.py`：完成回合聚合、成功门槛、阶段及范围钳制。
- `robot_env.py`：真实 step/reset 接线和评估日志恢复。
- `robot_env_cfg.py`：最低命令速度、异常位移阈值。
- `mdp/curriculums.py`：新默认函数与原 `lin_vel_cmd_levels_legacy` 对照。
- `config/curriculum_cfg.py`：显式列出评估阈值，地形课程不改。

基线切换只示意配置，不构造环境或开始训练：

```python
# cfg 已为 H2 环境配置；必须同时清除新函数参数
cfg.curriculum.lin_vel_cmd_levels.func = lin_vel_cmd_levels_legacy
cfg.curriculum.lin_vel_cmd_levels.params = {}
```

默认新函数需要真实 tracker，缺少接口时报错，不静默退回旧奖励门槛。运行期间更改课程参数会被拒绝，避免混用统计窗口。评估日志包括 `Curriculum/command_progress_episodes`、`success_rate`、`mean_ratio`、`expanded`、`generation` 和 `x_upper`（各项均带相同前缀）。其中 mean_ratio 是扣除 inactive 误差后的有效进度比，只汇总有效且有目标距离的回合；是否扩速由逐回合成功率决定。

网络输入、29 个动作、权重键形和观测归一化接口不变；进度统计不进入策略观测。本实现未提供统计窗口的 checkpoint 保存/恢复接口，重新构造环境会从空窗口积累，不能声称课程进度精确续跑。旧奖励课程的训练曲线与新课程不构成等价难度对照；若命令范围本身需要续跑，应由原配置显式恢复，本轮不读取权重。

## 验证与仍未证明的内容

CPU 检查覆盖：旧课程静止高奖励可扩速而新课程不能；有进度才通过；回退抵消与停止命令下的错误回退；命令切换和 yaw 旋转；纯侧移/斜漂；短回合与跌倒保留分母；少数快环境不能掩盖静止；异步 reset、不漏终止最后一步、不计 reset 传送；幂等、generation、上限、无效输入及异常传播。真实 AST 集成时序测试仅使用普通父类容器和实际 tracker，不启动 Isaac Lab。

完整数量及独立审查见 [验证记录](验证记录.md)。这些检查不证明行走稳定性提高、完整环境可执行或旧 checkpoint 的实际表现。按变化命令行走后回到起点仍可能正确跟踪命令，因此本课程也不代表完成台阶穿越；地形升级的径向位移问题仍应单独评估。
