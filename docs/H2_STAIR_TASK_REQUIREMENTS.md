# H2 自主上楼梯目标

机器人通过自身策略控制十二个腿关节，在保留原生驱动、关节限位、传感器随机化和身体终止条件的情况下完成上楼梯。上身十七个关节维持原有默认目标，不使用参考步态、额外重心控制或人工扶持。

训练从已独立通过平地门槛的策略出发，使用真实激光雷达重建的地形信息。输入包含原有五帧身体状态和五维运动上下文。继承的归一化保持冻结，优化状态与随机状态从新任务开始建立。

楼梯训练课程包含六级台阶，高度从三厘米逐步提升至十五厘米，踏面深三十五厘米、宽二点四米，接近距离一点四米。逐级有效交替落脚、持续承重、机器人根部实际净上升和顶部稳定停留构成训练中的进展证据。全回合接触力证据不合格后，不再获得该回合正向进展奖励，向后运动负债仍完整计入。

本次训练使用一千零二十四个环境，预算五千轮，每轮二十四个控制步。达到预算或触发原数值、资源、物理监督条件即结束，不自动延长或重试。训练指标与数值检查只用于监督，不代表上楼梯已经通过。

最终验收在 Isaac Sim 中独立执行一千零二十四个环境的首个完整九十秒回合。每个成功环境必须同时满足：

- 完成六级十五厘米台阶，每级双脚均有原有效交替落脚。
- 落脚前有效腾空八十至六百毫秒，承重持续至少八十毫秒。
- 全脚掌前后留有至少八毫米、侧面至少二十毫米余量。
- 真实净上升九十厘米，容差十厘米；顶部稳定至少两秒。
- 全回合存活，并保留同脚地面过滤力与原始力的正对照和一致性证据。

失败和无效环境均保留在完整分母中。至少九百二十二个相同环境同时满足全部条件，才认定本目标通过。平地通过、训练完成、检查通过或程序正常退出均不能代替这项验收。
