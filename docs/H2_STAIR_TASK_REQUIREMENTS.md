# H2 自主上楼梯目标

机器人通过自身策略控制十二个腿关节，在保留原生驱动、关节限位、传感器随机化和身体终止条件的情况下完成上楼梯。上身十七个关节维持原有默认目标，不使用参考步态、额外重心控制或人工扶持。

训练从已独立通过平地门槛的策略出发，使用真实激光雷达重建的地形信息。输入包含原有五帧身体状态和五维运动上下文。继承的归一化保持冻结，优化状态与随机状态从新任务开始建立。

新建楼梯训练在继承策略后，将十二个腿关节的随机探索标准差初始化到各自原有物理角度均方根上限。单侧髋俯仰、髋侧摆、髋偏航、膝、踝侧摆与踝俯仰的上限依次为零点零二、零点零一五、零点零一五、零点零二、零点零一与零点零零七五弧度，左右相同；最小标准差保持为各自上限的百分之五。训练中标准差可在原有边界内学习，关节确定性目标与完整动作范围保持原有权限。计划、启动请求、实际初始化、训练记录和模型记录共同核对这些参数；平地与通用训练的初始化比例保持原值。

楼梯训练的回报折扣与广义优势累计系数均为零点九九，每轮采样二十四个控制步，每步零点零二秒。每轮实际采样时长为零点四八秒，优势累计只使用这段采样内已有的时序残差及原有末端价值估计。计划、启动请求、解析后的训练配置、实际算法参数、原生训练记录和模型记录共同核对这些时间参数。更晚残差的权重用于本任务学习，其上楼效果仍须由独立物理验收判定。

楼梯训练包含六级十五厘米台阶，踏面深三十五厘米、宽二点四米，接近距离一点四米。运动目标固定为世界楼梯方向每秒三十厘米，并按当前完整姿态转换为原有身体坐标速度指令；原输入单位、身体坐标语义和冻结归一化保持不变。根刚体质心与根部原点的世界速度分别记录，避免混用测量位置。逐级有效交替落脚、持续承重、机器人根部实际净上升和顶部稳定停留构成训练中的进展证据。全回合接触力证据不合格后，不再获得该回合正向进展奖励，向后运动负债仍完整计入。

训练目标还包括抑制倾斜继续扩大，以及让前移的腾空脚掌完整越过真实台阶边缘。脚前缘进入立面前二十厘米时开始计算净空不足，直到脚掌最后缘越过该立面并留出八毫米余量，才转向后续真实台阶；脚尖先越过立面不会提前结束当前净空目标。仅对向前移动的卸载脚计算此代价，另一脚须实际承受至少七成体重。六条真实立面全部越过后结束该代价，顶部稳定和最终验收另按原条件判定。这些训练代价不指定步态相位、关节目标或固定身体高度，也不向策略额外提供仿真几何信息。

训练使用一千零二十四个环境，上限一千轮，每轮二十四个控制步。约五百轮的完整模型保存后，检查最近三次各含五千个完整回合的楼梯训练窗口；若均没有接触力证据合格的有效上阶落脚，则提前停止、保全记录并复盘修复。出现有效上阶进展则继续至原上限。失败和无效回合保留在分母中，未完整记录的初始回合不计入滚动窗口。数值、资源或物理监督条件优先执行，不自动延长或重试。训练指标与数值检查只用于监督，不代表上楼梯已经通过。

候选落脚约束的策略输出和导数使用与完整输入检查相同的原始批次，在得到批次输出后选取实际输入行，并独立核对前向结果与方向导数的一致性。原动作变化、数值误差和资源边界保持不变。

最终验收在 Isaac Sim 中独立执行一千零二十四个环境的首个完整九十秒回合。每个成功环境必须同时满足：

- 完成六级十五厘米台阶，每级双脚均有原有效交替落脚。
- 落脚前有效腾空八十至六百毫秒，承重持续至少八十毫秒。
- 全脚掌前后留有至少八毫米、侧面至少二十毫米余量。
- 真实净上升九十厘米，容差十厘米；顶部稳定至少两秒。
- 全回合存活，并保留同脚地面过滤力与原始力的正对照和一致性证据。

失败和无效环境均保留在完整分母中。至少九百二十二个相同环境同时满足全部条件，才认定本目标通过。平地通过、训练完成、检查通过或程序正常退出均不能代替这项验收。
