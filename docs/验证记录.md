## 验证边界

- 没有启动训练、仿真或真机控制，没有调用 `optimizer.step()`。梯度单测的 backward 只检查计算图。
- 没有读取或下载训练 checkpoint、USD 或产品 PDF，没有生成通过率、行走速度等实验成绩。
- 最新上游已提供真实 U-Net 和 H2 楼梯源码接线；本版已测试其 CPU 数据流，完整 Isaac Lab 执行仍未验证。不要再沿用旧快照“缺 U-Net / 无 H2 接线”的结论。
- Go2 来源权重、H2 morphology、零速度先验、传感器位姿/外参以及经验归一化器的兼容性尚需实际验证。启发式可靠性未校准，低可靠真实窄结构可能被去噪移除。
- 地图符号/偏移、缺失回波和速度来源修复会改变观测分布。旧策略和归一化器不能仅凭 state_dict 成功载入就直接视为兼容。
- TorchScript 测试出现 PyTorch 弃用提示；没有据此宣称 ONNX、Isaac 导出器或真机兼容。
- ruff 未安装；现有系统 mypy/black/pylint 入口发生 DLL 错误，因此不声称完成这些工具检查，也没有修改系统依赖来绕过它们。
